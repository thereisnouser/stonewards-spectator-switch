# Changelog

## 0.1.0

- LMB/RMB cycles through living dwarfs while dead.
- Shows a game-HUD spectator panel with clickable previous/next buttons, player name, count and shortcut hints.
- Hold ALT to use a visible cursor with the HUD buttons; release to restore the game's cursor mode.
- Keeps the game's own viewing angle instead of forcing camera rotation toward the selected dwarf.
- Skips dead/disconnected teammates and optionally advances when the current target dies.
- Clears the observation camera and hides the HUD when revived or leaving the run.
- Client-side only; no network commands and no installation required for other players.
