# Stonewards Spectator Switch

Client-only BepInEx 5 plugin for Stonewards. While your dwarf is dead, use **Left Mouse Button** to spectate the next living dwarf and **Right Mouse Button** to spectate the previous one.

The plugin uses the game's existing camera rotation and changes only its render-time position to the selected living dwarf's eye level. Mouse look is **not locked to the dwarf**; the player's normal camera orientation remains game-controlled. The plugin never teleports players, sends commands, or changes network state. This is a client-side view redirect, **not yet a native Stonewards spectator-target API integration**. The camera returns to normal on revival, lobby changes, or when the plugin is disabled.

## Build and install

Requirements: Stonewards (Mono), BepInEx 5 in your r2modman profile, and .NET SDK.

In PowerShell, from this repository folder:

```powershell
$profileDir = 'C:\Path\to\r2modmanPlus-local\Stonewards\profiles\stonewards-spectator-switch'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-and-install.ps1 `
  -GameDir 'F:\Steam\steamapps\common\Stonewards' `
  -ProfileDir $profileDir
```

The DLL installs into `<ProfileDir>\BepInEx\plugins\StonewardsSpectatorSwitch\`.

## Behavior

- Left click: next living teammate.
- Right click: previous living teammate.
- The first click selects a teammate; death does not automatically change your view.
- Skips dead/disconnected teammates.
- Switches to another living teammate if the current target dies (configurable).
- Ignores clicks in other input states such as inventory and menus.
- Preserves native camera rotation: look around normally while watching another dwarf.
- Defaults to the selected dwarf's eye position (no forced third-person chase angle).
- Returns to native camera behavior on revival or if no teammates are alive.

## Configuration

The file `BepInEx/config/com.thereisnouser.stonewards.spectatorswitch.cfg` is generated by BepInEx. You can change `General/Enabled`, `General/AutoAdvanceWhenTargetDies`, `Camera/OrbitDistance`, and `Camera/EyeHeight`.

## Test status

**Experimental 0.1.1 source.** The user confirmed 0.1.0 built and switched between dwarfs successfully; the camera angle was fixed, so 0.1.1 removes forced camera rotation. Version 0.1.1 is **not yet compiled or gameplay-tested**. This is still a render-time position redirect rather than the game's native spectator target API. This approach relies on Unity camera rendering callbacks; if Stonewards changes its render pipeline, it may need an update. If it fails, check `BepInEx/LogOutput.log` and confirm `Spectator Switch v0.1.1 initialized`.

## Upgrading from 0.1.0

The previous `Camera/Distance` and `Camera/Height` config keys are retired. The new `Camera/OrbitDistance` defaults to `0` so an existing r2modman profile does not retain a fixed behind-the-dwarf chase-camera offset. The new `Camera/EyeHeight` defaults to `1.55`.
