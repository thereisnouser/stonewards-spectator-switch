# Stonewards Spectator Switch

Client-only BepInEx 5 plugin for Stonewards. While your dwarf is dead, use **Left Mouse Button** to spectate the next living dwarf and **Right Mouse Button** to spectate the previous one.

The plugin locally changes the render camera to a third-person view of the selected dwarf. It never moves players, sends commands, or changes network state. It does not modify the game's native spectator target. The camera returns to normal on revival, lobby changes, or when the plugin is disabled.

## Build and install

Requirements: Stonewards (Mono), BepInEx 5 in your r2modman profile, and .NET SDK.

In PowerShell, from this repository folder:

```powershell
$profileDir = 'C:\Path\to\r2modmanPlus-local\Stonewards\profiles\stonewards-spectator-switch'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-and-install.ps1 `
  -GameDir 'F:\Steam\steamapps\common\Stonewards' `
  -ProfileDir $profileDir
```

The DLL installs into `<ProfileDir>\BepInEx\plugins\StonewardsSpectatorSwitch\`.

## Behavior

- Left click: next living teammate.
- Right click: previous living teammate.
- The first click selects a teammate; death does not automatically change your view.
- Skips dead/disconnected teammates.
- Switches to another living teammate if the current target dies (configurable).
- Ignores clicks in other input states such as inventory and menus.
- Returns to native camera behavior on revival or if no teammates are alive.

## Configuration

The file `BepInEx/config/com.thereisnouser.stonewards.spectatorswitch.cfg` is generated by BepInEx. You can change `General/Enabled`, `General/AutoAdvanceWhenTargetDies`, `Camera/Distance`, and `Camera/Height`.

## Test status

**Experimental 0.1.0 source.** Built against known public Stonewards API references, but **not compiled or gameplay-tested** in this environment. This approach relies on Unity camera rendering callbacks; the game may change its render pipeline in a future update. If it does not work, check `BepInEx/LogOutput.log`, confirm `Stonewards Spectator Switch v0.1.0 initialized`, and send the log plus your `Assembly-CSharp.dll` version for a native spectator API patch.
